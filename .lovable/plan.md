# Dr. Khalid Bin Amir portfolio

## Scope
- Replace the starter screen with one responsive portfolio page containing the requested navigation, introduction, biography, education, rotations, services, certifications, contact form/map placeholder, and footer.
- Keep every editable fact, label, link, and placeholder in one `content.ts` file.
- Use the supplied warm off-white, medical blue, warm greys, Manrope typography, strict radius scale, directional shadows, and restrained motion.

## Experience
- Build a desktop introduction with strong left alignment, a professional headshot placeholder, and one subtle CSS 3D medical loop; re-order these elements for mobile.
- Add gentle perspective lift to rotation cards, visible keyboard focus, semantic landmarks, 44px controls, reduced-motion support, and a mobile-only sticky Call action.
- Make navigation links scroll to their sections; appointment, phone, email, WhatsApp, LinkedIn, credentials, and form actions remain clearly editable placeholders where details were not supplied.

## Technical details
- Implement with React, Tailwind CSS v4, and Lucide icons already available in the project.
- Define all palette, typography, radius, shadow, and animation values as semantic tokens in the global design system.
- Add unique home-page SEO and social metadata, including a valid placeholder Open Graph image URL.
- Validate the finished page in the running preview at desktop and mobile sizes and fix any layout or accessibility-visible issues.
